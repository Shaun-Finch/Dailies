# Dailies

One shared board for your team's end-of-day AI round-ups. Each person pastes their round-up and every task lands on one board, sorted by status, sector, round, priority and next step.

Live: https://shaun-finch.github.io/Dailies/

- `index.html`: landing page
- `app.html`: the board
- `prompt.html`: the round-up prompt to give your AI
- `config.js`: Supabase project URL and publishable key (leave empty for a single-device board)
- `dailies-setup.sql`: database tables and access rules for shared team boards

Designed and built by [Shaun Finch](https://shaun-finch.github.io/Design/). Also shown on the portfolio at https://shaun-finch.github.io/Design/dailies/.
